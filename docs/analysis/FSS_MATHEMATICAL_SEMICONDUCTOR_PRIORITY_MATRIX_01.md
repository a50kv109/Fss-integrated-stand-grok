## 2. Математические приоритеты (Mathematical Priority Matrix)

Для проверки фундаментальных свойств симметрии (порядок группы, подгруппы, винтовые оси, скользящие плоскости, центровки) выделена матрица математических особенностей:

| Математическое свойство / Особенность | Репрезентативная группа | Обоснование / Проверяемый принцип |
|---|---|---|
| **Тождественная операция** | № 1 ($P1$) | Базовый контрольный случай ($W = I, w = 0$). |
| **Инверсия** | № 2 ($P\bar{1}$) | Наличие интринсической инцентральной симметрии ($i$). |
| **Винтовые оси ($2_1$)** | № 4 ($P2_1$), № 19 ($P2_12_12_1$) | Дробные трансляции вдоль оси вращения ($1/2$ вдоль $y$ или $z$). |
| **Скользящие плоскости ($c$)** | № 14 ($P2_1/c$), № 9 ($Cc$) | Отражение с одновременным сдвигом на $1/2$ по трансляционной решётке. |
| **Центрирование решётки ($C, I, F, R$)** | № 5 ($C2$), № 227 ($Fd\bar{3}m$) | Проверка трансляционных векторов центрирования ($1/2, 1/2, 0$ и др.). |
| **Сложные кубические группы** | № 227 ($Fd\bar{3}m$), № 216 ($F\bar{4}3m$) | Многократные оси симметрии 3-го и 4-го порядков, диагональные плоскости. |

## 4. Стратегия реализации и следующий пакет (Next Action Package)

Для поэтапного наращивания математической надёжности и прикладной ценности стенда предлагается следующий минимальный пакет изменений:

1. **Верификация группы № 5 ($C2$):** Проверить и окончательно разрешить расхождение центровки в реестре (`core/registry.ts`) и эталонном артефакте.
2. **Интеграция группы № 227 ($Fd\bar{3}m$, кремний / алмаз):** Добавить в `core/registry.ts` полную верифицированную модель для кремния, включая трансляции центрирования $F$ и оси симметрии.
3. **Интеграция группы № 216 ($F\bar{4}3m$, GaAs / 3C-SiC):** Добавить модель кубического полупроводника без инверсионного центра.
4. **Интеграция группы № 186 ($P6_3mc$, GaN / вюрцит):** Добавить гексагональную структуру с винтовой осью $6_3$.

Это позволит покрыть как математические тесты несимморфности и центрирования, так и ключевые полупроводниковые материалы мировой микроэлектроники.
