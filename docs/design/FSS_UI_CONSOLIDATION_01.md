## 1. Цель и задачи этапа

Приведение рабочего места исследователя 230 пространственных групп Фёдорова к единой прозрачной логике работы без дублирования действий и обеспечение полноценного переключения языков (русский / английский) без перезагрузки страниц и потери состояния.

## 3. Итоговая структура навигации

Четыре основных раздела приложения:

1. **Каталог симметрий (`Space-Group Catalog`):**
   - Главная точка входа.
   - Поиск по номеру ITA (1–230), символу Германа — Могена (HM) и символу Холла.
   - Фильтры по 7 кристаллическим системам (сингониям), решёткам Браве и статусу покрытия модели.
   - Мультивыбор чекбоксами, кнопка «Выбрать все 9 проверенных», кнопка «Загрузить демо-группу P4₁».
   - Кнопки перехода в «Паспорт» и быстрого экспорта одиночного проверенного `.fsspack`.

2. **Паспорт группы (`Group Passport`):**
   - Детальный паспорт выбранной пространственной группы.
   - Выбор кристаллографической установки / начала координат из 564 настроек Gemmi.
   - Таблица операций симметрии с точными целочисленными матрицами $W$ и рациональными сдвигами $w$.
   - Свидетельства математической проверки (нейтральный элемент, обратные элементы, замкнутость modulo 1).
   - Действия: «В очередь переноса» / «В очереди переноса ✓», «Экспортировать .fsspack», «Проверить операции в эксперименте».

3. **Экспорт и перенос (`Export / Migration`):**
   - Очередь выбранных для миграции пространственных групп.
   - Метрики готовности: общее число групп, готовые к экспорту (`MODEL_VERIFIED`), ожидающие модель (`CATALOG_METADATA_AVAILABLE`).
   - Скачивание индивидуальных `.fsspack` файлов.
   - Формирование и скачивание общего внешнего ZIP-архива (`INDEX.json`, `README.txt`, `packages/*.fsspack`).
   - Предпросмотр внутренней структуры архива.

4. **Эксперименты (`Experiments`):**
   - Детерминированный эксперимент над каноническим тетраэдром с $100\%$ математическим паритетом.
   - При передаче группы из паспорта — интерактивный баннер со списком точных кристаллографических операций группы.
   - Выбор предикатов проверки (`PRESERVES_STRUCTURE`, `PROPER_ROTATION`), порога погрешности $\varepsilon$.
   - Детерминированное свидетельство (Evidence JSON), 3D-вьюпорт и шина взаимодействия ИИ-агентов.

## 4. Архитектура и реализация переключения RU / EN

1. **Централизованный словарь (`core/i18n.ts`):**
   - Единый типизированный реестр `DICTIONARY` (153 ключа переводов).
   - Поддержка параметров интерполяции вида `{count}`, `{num}`, `{status}` в функции `translate()`.
   - Контекст `I18nProvider` и хук `useI18n()` для декларативного использования в любых компонентах: `const { t, lang, setLang } = useI18n();`.

2. **Переключатель в интерфейсе:**
   - Компактный двухпозиционный переключатель `RU | EN` расположен в верхнем правом углу шапки приложения.
   - Язык по умолчанию — русский (`ru`).
   - Выбор сохраняется в `localStorage` (`fss_lang`) и восстанавливается при повторном открытии.
   - Переключение происходит мгновенно, без перезагрузки DOM и без потери состояния выбранных групп или открытого раздела.

3. **Канонический словарь терминов:**
   - *Space-Group Catalog* $\rightarrow$ «Каталог симметрий»
   - *Group Passport* $\rightarrow$ «Паспорт группы»
   - *Export / Migration* $\rightarrow$ «Экспорт и перенос»
   - *Experiments* $\rightarrow$ «Эксперименты»
   - *Import Passport* $\rightarrow$ «Импортировать паспорт»
   - *Export `.fsspack`* $\rightarrow$ «Экспортировать `.fsspack`»
   - *Batch ZIP* $\rightarrow$ «Общий ZIP-архив»
   - *Verified Active* $\rightarrow$ «Проверен, допущен к работе»
   - *Metadata Available* $\rightarrow$ «Доступны метаданные»
   - *Model Pending* $\rightarrow$ «Математическая модель не подготовлена»
   - *Quarantine Diagnostic* $\rightarrow$ «Диагностический карантин»
   - *Rejected* $\rightarrow$ «Отклонён»

4. **Непереводимые кристаллографические инварианты:**
   - Номера групп ITA (1–230), стандартные символы Германа — Могена ($P4_1$, $Fm\bar{3}m$, $P2_1/c$), символы Холла ($P 4w$), имена файлов (`manifest.json`, `INDEX.json`, `*.fsspack`), элементы матриц $W \in \mathbb{Z}^{3\times3}$ и дроби $w \in \mathbb{Q}^3$ сохранены в международной стандартной записи.
